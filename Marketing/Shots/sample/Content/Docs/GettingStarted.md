# Getting Started

Welcome to the project. This page takes you from a fresh clone to a running level in about ten minutes.

## Before you open the editor

1. Install **Unreal Engine 5.8** from the launcher.
2. Clone the repository and pull the large files.
3. Run `Setup.bat` once, then open `Demo.uproject`.

> The first launch compiles shaders. Go and make a coffee.

## Where things live

- `Content/Maps` holds one folder per level.
- `Content/Environment` holds shared art, sorted by type.
- `Content/Blueprints/Core` holds the game mode and player classes.

Every folder that needs explaining has a `README` beside its assets, so look there first.

## Your first change

Open [Level Design](LevelDesign.md), pick a greybox from the backlog, and work in your own sublevel.

## Getting help

Ask in the team channel, or read the [Naming Conventions](NamingConventions.md) if a review sent you here.
